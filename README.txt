# StallFest Website

Open `index.html` in a browser.

Included:
- Home page
- Create Stall
- Maximum 3 students
- Technical / Non-Technical / Food category
- ₹100 payment confirmation
- Google Pay QR image upload
- Give Rating
- Customer Name/ID
- One rating per Customer ID per stall
- Live average ratings
- Highest-rated stalls shown first
- Data saved in browser localStorage

Important:
This is a working frontend prototype. The payment checkbox is only a demo confirmation; it does not verify a real Google Pay transaction. For a real event website, connect Firebase and a payment gateway/verified payment workflow.
